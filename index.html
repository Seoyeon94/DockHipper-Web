How to Install

애플 공증 받은 앱이라 경고 없이 사용해 보세요

  1. 1 ↓

    Download

    DockHipper.zip을 다운로드해요.

  2. 2 ▣

    Unzip

    압축을 풀어요.

  3. 3 A

    Move to Applications

    DockHipper.app을 응용 프로그램 폴더로 옮겨요.

  4. 4 ⚙

    Allow Accessibility

    손쉬운 사용 권한을 허용해 주세요.

‘설정 > 개인정보 보호 및 보안 > 손쉬운 사용 > Hipper’

Dock의 상태를 정확히 알기 위해 제어 허용이 필요해요!

사용 중 Dock을 잘 인식하지 못한다면
손쉬운 사용에서 ‘Hipper’를 ‘비활성화’ 후 다시 허용해 주세요.
